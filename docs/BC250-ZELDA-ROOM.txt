Repeated room performance
Platform: BC250, Bazzite Deck, RADV GFX1013, Mesa 26.2.1. Both arms use the
same -O3 -g -DNDEBUG -fno-omit-frame-pointer build flags, 1x handheld resolution,
NoSharpen, Fast GPU accuracy, frame generation off, and FSR/DLSS off. The normal
hardware/affinity policy is retained. The default AppImage build remains O2;

Runs were sequential A1/B1/A2/B2, with independent profiles and the same room

inputs, screenshots, profiling, RenderDoc or verification flags run inside
either measured window. The debug endpoint remains enabled. Other emulator
checks were empty, and each owned process ended with focus restored.
